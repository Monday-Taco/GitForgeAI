# GitForgeAI

AI-powered GitHub repository generator.

## Overview

GitForgeAI allows developers to describe a project in natural language and automatically generate a GitHub repository structure.

Example prompt:

> Create an ecommerce platform with Spring Boot, Angular and PostgreSQL.

The application generates:

* Repository name
* Project description
* README
* Repository structure (future feature)
* GitHub repository creation (future feature)
